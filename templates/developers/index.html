Medifinance API

Authentication

Send your API key in the Authorization header: 

Authorization: Bearer mfk_…

Keys are issued by Medifinance staff against your organisation and shown to you exactly once. Treat them like a password — store in a secrets manager, not in source. You can hold more than one key at a time so you can rotate cleanly: issue the new one, switch traffic, then ask for the old one to be revoked. Sandbox and production keys come from separate environments — call the right base URL for the key you're using.

Create a deal

POST /api/deals/

Content-Type: application/json

Creates a deal introduced by your organisation. We attach a quote for every term we can currently fund at that amount (the cheapest lender per term), raise the standard document requests, and notify our team — no further call needed to get the application moving.

Request body

FieldTypeRequiredNotes
namestringyesA short label for the deal, e.g. the purchase it funds.
amountnumberyesAmount to finance in GBP. Must be > 0.
first_namestringyesThe applicant's first name.
last_namestringyesThe applicant's last name.
emailstringyesThe applicant's email address.
ltdbooleanyesWhether the applicant's business is a limited company.

Response (201)

{
  "id": 42,
  "name": "Dental chair refit",
  "amount": "25000.00"
}

curl example

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/deals/ \
  -H "Authorization: Bearer mfk_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"name": "Dental chair refit", "amount": 25000,
       "first_name": "Jane", "last_name": "Smith",
       "email": "jane@example.com", "ltd": true}'

Try it

Paste your key and we'll POST the form to /api/deals/ from your browser — same request your integration would make. This creates a real deal against your organisation.

Response

Get a quote

POST /api/quotes/

Content-Type: application/json

Request body

FieldTypeRequiredNotes
amountnumberyesLoan principal in GBP. Must be > 0.
term_monthsintegeryesLoan term in whole months. Must be > 0.
commission_percentnumbernoOptional gross-up on the monthly payment. Defaults to 0.

Response (200)

{
  "amount": "25000.00",
  "term_months": 60,
  "commission_percent": "0.00",
  "lender": "BNP Paribas",
  "monthly_payment": "526.79",
  "apr": "9.64",
  "flat_rate": "5.29",
  "total_interest": "6607.40"
}

Monetary and percentage values are JSON strings with 2 decimal places. Parse them as decimals (not floats) if you're doing further arithmetic — values are computed at full precision and rounded only at the end.

curl example

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/quotes/ \
  -H "Authorization: Bearer mfk_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"amount": 25000, "term_months": 60}'

Try it

Paste your key, fill in an amount and term, and we'll POST it to /api/quotes/ from your browser — same request your integration would make.
